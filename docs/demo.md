# InsightPilot 五分钟演示

完整安装、API/MCP 启动和评测复现步骤见 [快速启动与复现](quickstart-evaluation.md)。

## 演示顺序

1. **0:00–0:45**：展示企业合成数据、UTC 日期和批准退款指标定义。
2. **0:45–1:40**：调用 API 问明确日期与地区的金额率；展示计划、SQL 参数和独立复核。
3. **1:40–2:20**：问含糊的“退款率”；展示澄清，不替用户选订单率或金额率。
4. **2:20–3:00**：请求手机号或提示注入；展示 guard 拒绝且不调用模型。
5. **3:00–3:50**：连接 MCP，查看 `analyze_refund` 与指标目录，再运行同一分析。
6. **3:50–4:30**：展示 run 查询、脱敏记录、失败状态与重启恢复测试。
7. **4:30–5:00**：展示 v4 模型臂和规则基线，分别说明实际模型回答、guard、澄清与拒绝分母。

只展示 [当前评测报告](../reports/current-benchmark/evaluation.md) 的实测数字。小样本合成集不证明生产可靠性或泛化。

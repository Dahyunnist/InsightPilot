# S12 学习记录：语义与运行时故障修复

## 按 v2 证据修复

- 规划前拒绝明显的“忽略系统要求/绕过复核/编造结果”注入模式，避免无效模型结构进入后续流程。
- 只允许目录中的地区值；从用户原句抽取规范值。因此“华东地区”落到数据字面值“华东”；未提及地区时，模型不能自行添加过滤条件。Agent 核心再做一次已知地区校验。
- 对每个候选指标比较 `effective_from` 和请求区间；旧日期先澄清，不让 LLM 擅自越过定义生效期。无检索消融也在选中指标后应用同一生效日检查。
- 退款事件日语言补入事件指标检索词。

## 系统运行证据

新增独立进程打开同一 SQLite run store：启动中的记录恢复为 `interrupted`，已完成 run 可由重建后的 API 读取。API 与真实 MCP streamable HTTP 都验证未授权请求返回 401；请求中的电话和邮箱不会进入审计表，响应也不回显凭证。

并发上限、429、跨请求取消由 S7 的阻塞 planner 集成测试覆盖；MCP/API scope、重启中断恢复、90 天清理和文本脱敏由 S6 原有测试覆盖。S12 新增错误地区、空结果对非空 cohort、注入拒绝、生效日期与真实进程重启测试。

## 结果边界

没有重跑已暴露的 v2；它只保留修复前证据。S12 测试证明确定性路径，不证明真实模型在新 holdout 上提升。要验证模型泛化，需要另建未暴露 v3、冻结 manifest 后再评测。

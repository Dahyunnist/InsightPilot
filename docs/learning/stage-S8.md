# S8 学习记录：轨迹与可解释奖励

## 目标

让每次分析都留下阶段结果，方便定位失败；用独立 gold 奖励正确指标、维度、数值和复核。轨迹只记录阶段状态，不记录问题文本或模型思维链。

## 实现

轨迹阶段为 preflight、planning、compilation、query、verification、answer。每步状态为 passed、blocked 或 not_reached。拒答和澄清分别停在 preflight 与 planning；失败按实际 stage 截断。

企业评测奖励由可检查信号相加：指标正确 +0.5、维度正确 +0.5、数值正确 +1、独立复核通过 +1。澄清或拒绝给 +0.25；SQL 执行或复核失败扣 1。奖励供离线诊断，不能替代安全策略，也不等价于强化学习。

## 验证与限制

测试覆盖成功轨迹和预检拒绝轨迹。S8 不重跑付费模型评测；S7 原始记录保留当时结果。新增轨迹和奖励随之后的评测运行产出。小样本奖励只适合调试，不用于声称泛化或 Agentic-RL。

## X01 / X12 失败复审

离线复核保存的真实模型响应，不重发请求。X01 题目明确要求“批准退款的付款订单占比”，但 `retrieve_metrics` 把通用“占比”优先当成金额贡献度，候选只剩 `approved_refund_amount_contribution`。这是检索排序缺陷，不是 gold 歧义。修正规则：带“订单占比/订单比例/订单率/订单数”时不因通用“占比”加金额贡献分；X01 精确题面现命中 `approved_refund_order_rate`。新增 X01 规划回归及金额份额正例，均不调用模型。

X12 问“批准退款金额与实收金额的比值”。gold 对应 `approved_refund_amount_rate`，其目录公式为“批准退款金额 / 对应订单实付金额”；真实模型仍把分子和分母拆成两个独立指标并澄清。保留该严格失败，不改 gold、不改原报告、不重跑模型。当前只修复并验证 X01 的确定性召回缺陷；X01 新评分和 X12 的模型规划表现都需要新冻结集与另行授权/预算预检后的真实评测确认。

这组实验用于隔离检索对指标选择和最终查询正确率的影响。两臂共用相同问题、模型、温度、输出约束和本地执行/验证链路，只改变指标候选上下文。模型只生成受限 JSON 查询计划，SQL 编译、只读策略、数据库执行和独立复核仍由程序完成。模型结果见下方 2026-11-16 宿主运行审计；小样本不支持生产或总体准确率结论。
